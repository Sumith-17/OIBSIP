# Fyodor Dostoevsky — Literary Tribute

A simple tribute website dedicated to **Fyodor Dostoevsky**, one of the most influential writers in Russian literature.

The website presents a short overview of his life, important events through a timeline, some of his major works, and his literary legacy.

## How It Was Made

The website was built using:

* HTML5 for the structure and content
* CSS3 for styling and layout
* Flexbox and CSS Grid for different sections
* Media queries for responsive design
* CSS transitions and hover effects for subtle interactions

The design uses a simple editorial style with serif typography, muted colors, borders, and a grayscale portrait to match the literary theme.

The website is fully responsive and adapts the layout for desktop, tablet, and mobile screens.
