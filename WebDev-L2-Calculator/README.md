# Calculator

A simple browser-based calculator built using HTML, CSS, and JavaScript.

This project was created as part of the OASIS INFOBYTE Web Development Level 2 internship.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear all input using the AC button
- Backspace to remove the last entered character
- Displays the current expression and result
- Supports multiple operations in a single expression
- Handles multiplication and division before addition and subtraction
- Displays an error when trying to divide by zero
- Calculator buttons are handled using JavaScript event listeners

## Technologies Used

- HTML5
- CSS3
- JavaScript

1. Download or clone the project.
